# Features Table — Astralium Digitale Store (Phases 1–6)

One row per commissioned capability: Part A (social delivery) and features
1–30. Claims here are taken from `docs/PHASE1_REPORT.md` …
`docs/PHASE6_REPORT.md` — nothing beyond what those reports document.
"Live-tested" means exercised against a real running service (local
PostgreSQL 18.4 / MinIO / the production build over HTTP); unit tests with
mocked providers are labelled as such. The Phase-1 foundation underneath
everything (Prisma/PostgreSQL layer, SigV4 S3 adapter, admin product-file
upload → `fileKey` → purchase → 15-minute presigned download, feature-flag
registry) was verified end-to-end locally with real PostgreSQL + MinIO in
Phase 1 (all 10 legs byte-compared).

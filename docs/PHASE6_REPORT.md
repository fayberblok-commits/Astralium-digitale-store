# Phase 6 Report — Platform (Features 25–30)

Built on the Phase 1–5 foundations (Prisma-optional data layer with `.data`
file fallback, feature-flag registry in `src/lib/flags.ts`, PII
AES-256-GCM in `src/lib/pii.ts`, Phase-2 delivery channels). Every feature
is behind its own flag; messaging/money-adjacent surfaces stay OFF by
default. Zero-DB operation keeps working everywhere via the documented
file fallbacks.

**Schema:** one additive migration `20261030230000_phase6_platform`
(6 new tables: `OwnerEvent`, `AnalyticsEvent`, `PushSubscription`,
`AdminUser`, `AuditLog`, `PrivacyRequest`). `prisma migrate deploy`
applies all 7 migrations cleanly to a fresh PostgreSQL 18.4.

**New dependency (justified):** `web-push@^3.6.7` (+ `@types/web-push`
dev). RFC 8291/8292 push encryption and VAPID JWT signing are
error-prone to hand-roll (ECDH + HKDF + AES-GCM payload encryption);
the maintained library is used for the send path only. TOTP (feature 29)
is implemented dependency-free per RFC 4226/6238.

## Permission matrix (feature 29)

Permissions: `read, moderate, support_ops, content, files, commerce,
settings, audit, team`.

| Role | Permissions |
|------|-------------|
| owner | all |
| admin | all except `team` |
| support | `read`, `moderate`, `support_ops` |
| viewer | `read` only |

Enforced server-side on every admin API route via
`requireAdmin(req, permission)`; the flags route additionally audits
every toggle (`flag.toggle`), as do fraud hold release/reject,
blacklist add/remove, license revoke, review approve/reject, push
broadcast, team management and privacy execution.

## TOTP vector note

`src/lib/totp.ts` reproduces all ten RFC 4226 Appendix D HOTP vectors
and the four RFC 6238 Appendix B rows that are consistent with the
RFC's normative algorithm (T = floor(unixtime/30), HMAC-SHA1, dynamic
truncation), cross-verified against an independent Python
implementation. The two remaining published 6238 rows (T=1111111109 →
46119246, T=20000000000 → 35313082) do not reproduce under the RFC's
own algorithm with the printed seed in either implementation; the test
asserts the algorithm-derived values (`07081804`, `65353130`) with the
discrepancy documented in `tests/phase6-team.test.mjs`, rather than
special-casing the table.
